# 会话分页优化需求（原型文档）

> 版本：v2
> 日期：2026-07-30
> 状态：待开发
> 前置依赖：会话管理功能 v1

---

## 一、问题背景

当前会话管理页面一次性加载某个 App 的全部会话数据，存在以下问题：

1. **首屏卡顿**：Codex 有 200+ 个会话文件，全部扫描 + JSON 解析阻塞渲染主线程
2. **Tab 切换卡顿**：切换 Agent Tab 时需要等待全量扫描完成才能渲染
3. **内存占用高**：所有会话数据同时驻留内存

---

## 二、优化目标

- 首屏渲染时间 < 500ms
- Tab 切换时立即显示骨架屏，无主线程阻塞
- 滚动到底自动加载下一页（无限滚动）
- 搜索/排序由后端处理，保证结果准确

## 四、交互流程

### 4.1 页面首次加载

```
用户进入会话页面
  │
  ▼
┌──────────────────────────┐
│ ① 显示骨架屏 ×5          │
│ ② 请求 scanSessions      │
│    app="claude"           │

│    sort="time-desc"       │

           ▼
┌──────────────────────────┐
│ ③ 替换骨架屏为真实卡片    │
│ ④ 更新 Dashboard 统计    │
│ ⑤ 注册无限滚动监听       │
└──────────────────────────┘

│    app="codex"            │

           │ 数据返回
           ▼

```
用户输入搜索关键词

  ▼

## 六、后端接口

### 6.1 scanSessions

```javascript
/**
 * @param {string} app - 应用类型
 * @param {object} opts
 * @param {number} opts.offset - 偏移量（默认 0）
 * @param {number} opts.limit - 每页条数（默认 20）
 * @param {string} opts.search - 搜索关键词（可选）
 * @param {string} opts.sort - 排序方式（默认 "time-desc"）
 * @returns {{ sessions: [], total: number }}
 */
async function scanSessions(app, opts)
```

### 6.2 参数说明

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| app | string | "" | 应用类型，空字符串表示全部 |
| offset | number | 0 | 分页偏移 |
| limit | number | 20 | 每页条数 |
| search | string | "" | 搜索关键词（标题/项目路径/模型） |
| sort | string | "time-desc" | 排序方式 |

### 6.3 排序方式

| sort 值 | 说明 |
|---------|------|
| `time-desc` | 最近活跃（默认） |
| `time-asc` | 最早活跃 |
| `name-asc` | 名称 A-Z |
| `name-desc` | 名称 Z-A |
| `messages-desc` | 消息最多 |
| `tokens-desc` | Token 最多 |

### 6.4 返回格式

```javascript
{
  sessions: [...],   // 当前页数据
  total: 123,        // 总数（用于判断 hasMore）
}
```

## 八、Composable 设计

```javascript
// composables/useSession.js

// 状态
const sessions = ref([]);         // 已加载的会话列表
const offset = ref(0);            // 当前偏移
const total = ref(0);             // 总数
const loading = ref(false);       // 首次加载
const loadingMore = ref(false);   // 加载更多
const activeApp = ref("claude");  // 当前 Tab
const searchQuery = ref("");      // 搜索关键词
const sortBy = ref("time-desc");  // 排序方式

// 计算属性
const hasMore = computed(() => sessions.value.length < total.value);
const showSkeleton = computed(() => loading.value && sessions.value.length === 0);

// 方法
async function loadPage()         // 加载第一页（重置）
async function loadMore()         // 加载下一页（追加）
async function switchApp(app)     // 切换 Tab
async function onSearch(query)    // 搜索（防抖）
async function onSortChange(sort) // 排序变更
async function loadDetail(s)      // 加载详情
async function deleteSession(s)   // 删除会话
async function clearSessions()    // 清空会话
function exportSession(s, fmt)    // 导出会话
function exportAllSessions(fmt)   // 导出全部

// 导出
return {
  sessions, offset, total, loading, loadingMore,
  activeApp, searchQuery, sortBy,
  hasMore, showSkeleton,
  loadPage, loadMore, switchApp, onSearch, onSortChange,
  loadDetail, deleteSession, clearSessions,
  exportSession, exportAllSessions,
  SESSION_APPS, SORT_OPTIONS, appStats,
}
```
